# Threads @siapnikahindo — 5 teks per hari

Slot: 07:00, 10:00, 13:00, 17:00, 21:00 WIB → `threads/queue/<YYYY-MM-DD>-<1..5>.json`
(`publish_after`, `text` ≤500 karakter, `topik`). Diposting `scripts/threads_post.py`
lewat workflow `threads.yml` (+ dipicu run cadangan `wp-cron.yml`), lalu pindah ke `threads/posted/`.

Gaya: ngobrol, satu ide per posting, ajak diskusi (pertanyaan di akhir), hangat & islami-friendly,
tanpa link, tanpa/maks 1 hashtag, tanpa kata "AI/robot/coach". Variasi: pertanyaan, opini ringan,
pengingat pagi/malam, "buat yang sudah menikah…", mitos vs fakta. Topik tidak boleh mengulang 14 hari terakhir.
Reel (IG/FB/YT) TIDAK lagi memposting ke Threads — Threads khusus 5 teks ini.
